# 框架使用说明

## 公平输入

所有框架的模型只收到相同的 `Question`、system prompt、知识快照、模型、temperature=0、variant、seed、超时和预算。task_id 与 category 只由 runner 用于运行标识和分组统计。gold、aliases、source 和父仓库 scorer 也只在统一 runner 内可见。

## T1 Direct

一次 `/chat/completions` 请求。无工具、无自我修正循环。为保持知识可达性，快照按路径排序后完整注入 prompt。

## T2 LangGraph

使用 `create_agent` 与流式 ReAct。三个工具为 `list_knowledge_files`、`search_knowledge`、`read_knowledge_file`，均为只读。

## T3 smolagents

使用 `CodeAgent`，允许模型以 CodeAct 方式组合相同的只读知识工具；禁用额外 Python import。

## T4 OpenHands

使用 `load_skills_from_dir`、`AgentContext`、`Agent` 和 `Conversation`。技能正文由原生 `invoke_skill` 渐进披露；三个自定义工具只负责列出、检索和读取公开参考文件，不提供 `read_skill` 旁路。

## T5 CrewAI

顺序执行 researcher、answerer、reviewer。三者均只读；reviewer 根据前两角色上下文核查证据并输出最终短答案。

## T6 OSIS-AI

每题建立独立 `.agents` 和 XDG config/data/cache/state 目录，复制固定父仓库或显式指定的原生 `AGENTS.md`，再追加实验边界指令、挂载相同快照并启动 OpenCode server。OpenCode 禁止 Shell、编辑和外部目录访问；子进程只保留本次模型网关所需的 key。通过父仓库 `opencode_client` 创建单独会话。T6 始终串行，防止本地端口和状态竞争。
