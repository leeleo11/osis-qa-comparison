# 问答线实验数据后处理

跑完后的 `runs/` 和 `results/` 都不进 Git。后处理只读已结束的 run。标准答案不写入汇总；CSV 里的 `pred` 是模型抽出的答案，不是金标准。

只统计有 `evaluation.json`、且 `manifest.json` 状态为 `completed` 或 `failed` 的目录。路径里带 `_archive` 的旧尝试跳过。

## 汇总

在仓库根目录执行：

```powershell
uv run python scripts/summarize_results.py `
  --runs-dir runs\formal-qa `
  --output results\formal-qa
```

输出两个文件：

| 文件 | 内容 |
| --- | --- |
| `summary.json` | 按架构汇总：题数、答对数、失败数、准确率、平均耗时、效率、综合分，以及按题目分类的准确率 |
| `records.csv` | 每条 run 的架构、题号、分类、状态、失败码、是否答对、抽出的答案、耗时、目录 |

综合分是准确率 80% 加效率 20%。效率为 `1 / (1 + 平均耗时秒 / 240)`。失败、超时或没有最终答案的题记为未答对，仍留在分母里。`summary.json` 里的 `failed_ids` 列出失败题号。

需要把表给别人时，去掉 `records.csv` 的 `pred` 和 `run_dir` 再另存。
